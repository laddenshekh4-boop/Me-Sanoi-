# Mr Sanoi — Deal Finder Frontend

A polished, mobile-responsive frontend MVP for a cheap-product discovery and price-drop comparison website.

## Included
- Mr Sanoi branding/logo
- Search UI
- Men/Women/Electronics/Fashion filters
- Budget filters
- Rating filter
- Sorting by price/rating/reviews/drop
- Cheap & highly-rated product cards
- Price-drop section
- Store price comparison modal
- Responsive mobile design
- Demo data only

## Run
Open `index.html` in a browser, or use VS Code Live Server.
